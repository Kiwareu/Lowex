# Security Policy

## 数据与隐私 / Data & privacy
Lowex 在本机完成全部配置生成，不运行服务器、不上传节点或订阅。唯一的网络请求：规则图标（内置；可选的公开图标库补充）与可选的 App Store 搜索（iTunes Search API）。

Lowex generates configs entirely on-device. No servers, no telemetry. Network use is limited to rule icons and the optional App Store search.

## 报告漏洞 / Reporting a vulnerability
请**不要**在公开 Issue 中贴出节点、订阅链接、令牌等敏感信息。请使用 GitHub 的 **Security → Report a vulnerability**（私密安全公告）提交；一般问题与功能建议请开 Issue。

Please never post nodes, subscription URLs or tokens in public issues. Use GitHub's **Security → Report a vulnerability** (private advisory). Use issues for ordinary bugs and feature requests.

## 支持版本 / Supported versions
仅最新的 release。 / Only the latest release.
