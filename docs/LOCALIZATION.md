# 本地化 / Localization

## 语言
| 选项 | 表文件 | 说明 |
|---|---|---|
| 跟随系统 | — | 按系统首选语言：简体 → 简体；`zh-Hant` / `-TW` → 台灣繁體；`-HK` / `-MO` → 香港繁體；其余 → English |
| 简体中文 | （无，原文） | 源码中文原文即简体中文 |
| 繁體中文（台灣） | `zh-Hant-TW.json` | OpenCC `s2twp`（含台灣用语：軟體 / 網路 / 檔案 / 資訊 / 預設 / 設定 / 伺服器 / 程式…） |
| 繁體中文（香港） | `zh-Hant-HK.json` | OpenCC `s2hk` + 香港写法（軟件 / 網絡 / 文件 / 數據 / 戶 / 營運商…；預設 / 設定 / 資訊 与台灣一致） |
| English | `en.json` | 人工翻译 |

**为什么拆成台灣 / 香港两张表**：常用界面用词确有差异（軟體 / 軟件、網路 / 網絡、資料 / 數據、檔案 / 文件、客戶端 / 用戶端 等），所以分开；两张表条目完全一致，缺任何一条都会被检查脚本发现。

## 机制
- 翻译表在 `native/Resources/Lang/*.json`：**key = 简体中文原文**，value = 译文；`{}`（按顺序）与 `{1}` `{2}`（按位置）是占位符。
- Swift 里用 `L("中文原文", 参数…)`（见 `Sources/Lang.swift`）。
- 引擎（`engine.js`）返回的分组名 / 说明 / 防泄漏文案 / 校验与警告，在 `Engine.call` 边界按「精确匹配 → 带占位符的模式 → 「【配置取证】…」复合句 → 空格拼接句」翻译；引擎内部与生成的配置**不翻译**。
- 切换语言：`Store.reloadLanguage()` 刷新目录，根视图用 `.id` 重建，立即生效；选择存在 `UserDefaults`（`lowex.lang.choice.v1`）。

## 刻意不翻译
- 生成的配置正文、注释、策略组名称（一键代理 / 漏网之鱼 / 资源更新 等）保持中文，保证各语言下生成物一致、且不破坏既有配置的引用。
- App 名称库（微信、淘宝、哔哩哔哩 …）保持原名；关于页的更新日志条目保持中文。

## 检查
`python3 tools/check-i18n.py [Lang 目录或解包的 .app]`：三表 key 一致、占位符一致、源码里所有 `L("…")` 都有译文、English 表无汉字、繁体表无简体残留。CI 构建出的 IPA 也用此脚本检查。
