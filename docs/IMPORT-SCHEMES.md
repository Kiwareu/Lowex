# 导入 URL scheme（3.6.0，均需配置的远程 https 地址）
| 客户端 | scheme | 依据 |
|---|---|---|
| Surge | `surge:///install-config?url=<enc>` | Surge 官方文档 |
| Loon | `loon://import?sub=<enc>` | Loon 官方文档 |
| Stash | `stash://install-config?url=<enc>` | Stash 官方文档 |
| Egern | `egern:/profiles/new?name=&url=` | Egern 官方文档 |
| sing-box | `sing-box://import-remote-profile?url=<enc>#<name>` | sing-box 官方文档 |
| Karing | `karing://install-config?url=&name=` | karing.app/cooperation/scheme |
| Clash Verge Rev | `clash://install-config?url=<enc>` | clashverge.dev/guide/url_schemes |
| FlClash | `clash://` / `clashmeta://` / `flclash://install-config?url=` | FlClash README |
| Clash Mi / CMFA / Clash Party | `clash://install-config?url=` | Clash 通用约定（Clash Mi 与 Karing 同作者） |
| Shadowrocket | `shadowrocket://config/add/<url>` | 社区通用写法，官方无文档 |
| Quantumult X | 无整份配置导入 scheme（`quantumult-x:///update-configuration?remote-resource=` 仅资源片段） | QX 官方示例 |
